## Penjelasan Fitur

### 1. Manajemen Fasilitas
Fitur ini digunakan oleh admin untuk mengelola data fasilitas kampus, seperti gedung, ruangan, dan barang inventaris. Admin dapat menambahkan, melihat, mengubah, dan menghapus data fasilitas, serta mengatur informasi kapasitas, stok, kondisi, kategori, dan status ketersediaan fasilitas. Mahasiswa dapat melihat katalog fasilitas beserta detail informasinya.

### 2. Pengajuan Peminjaman
Fitur ini digunakan oleh mahasiswa untuk mengajukan peminjaman fasilitas kampus. Mahasiswa dapat melihat katalog fasilitas, memeriksa ketersediaan, memilih fasilitas yang ingin dipinjam, mengisi informasi kegiatan dan tanggal peminjaman, serta mengunggah dokumen persyaratan. Mahasiswa juga dapat melihat riwayat dan status pengajuan yang telah dibuat, termasuk melakukan perubahan atau pembatalan jika masih diperbolehkan oleh sistem.

### 3. Verifikasi dan Persetujuan
Fitur ini digunakan oleh admin untuk memeriksa dan memproses pengajuan peminjaman dari mahasiswa. Proses persetujuan dilakukan melalui dua tahap, yaitu verifikasi kelengkapan pengajuan dan persetujuan akhir. Admin dapat menerima pengajuan untuk diproses lebih lanjut, meminta revisi, menolak, atau memberikan persetujuan akhir dengan mempertimbangkan penanggung jawab fasilitas. Setiap keputusan akan tercatat dalam riwayat persetujuan.

### 4. Pengembalian dan Pelaporan
Fitur ini digunakan oleh admin untuk mengelola proses serah terima dan pengembalian fasilitas yang telah dipinjam. Admin dapat mencatat kondisi awal fasilitas saat diserahkan dan kondisi akhir saat dikembalikan. Jika ditemukan kerusakan atau kehilangan, admin dapat membuat laporan serta memperbarui kondisi dan stok fasilitas. Fitur ini juga menyediakan laporan dan statistik peminjaman yang dapat difilter serta diekspor ke format PDF atau Excel.

### Fungsi Website
FASLINK dikembangkan untuk meningkatkan efisiensi pengelolaan fasilitas kampus, mempermudah mahasiswa dalam melakukan pengajuan peminjaman, membantu petugas dalam memantau ketersediaan fasilitas, serta menyediakan pencatatan transaksi peminjaman dan pengembalian yang lebih terstruktur.
